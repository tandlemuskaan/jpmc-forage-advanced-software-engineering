# JPMorgan Chase & Co. – Advanced Software Engineering Job Simulation (Forage)

## Overview

This repository contains my completed solution for the **JPMorgan Chase & Co. Advanced Software Engineering Job Simulation** hosted on Forage.

The simulation focuses on building and improving a backend financial transaction processing system using Java and Spring Boot. Throughout the tasks, I worked with real-world backend development concepts such as REST APIs, databases, Kafka messaging, and automated testing.

> **Note:** 
> This project was completed as part of the Forage virtual job simulation using the starter code provided by JPMorgan Chase & Co. My contributions include completing the assigned engineering tasks and implementing the required functionality.

## Running the Project

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/jpmc-forage-advanced-software-engineering.git
```

### Navigate into the project

```bash
cd jpmc-forage-advanced-software-engineering
```

### Run the application

```bash
./mvnw spring-boot:run
```

For Windows:

```bash
mvnw.cmd spring-boot:run
```
